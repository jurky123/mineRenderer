# alpha.46：GPU 首次执行与预热门禁

alpha.45 上传的 `rt-suite-1791460810949.zip` 完成 13 段，在第 14 段配置可用后约 36 秒无 GPU timing 样本时，被错误归因为耗时不稳定。用户日志还记录另一次第 10 段相同中断，以及远程服务器 connection reset。首次管线创建曾用 48 / 118 秒；最后一次第 14 段创建仅 136 ms，后续停顿不能仅凭日志归因为管线创建。

## 已修正

- 渲染器就绪后等待首个完成的 GPU batch timestamp，独立 180 秒门限。
- 首个样本后等待 30 个样本，独立 180 秒门限。
- 完整样本窗口到达后才启动 30 秒 GPU 稳定性门限；仍保持两半中位数 10% 判定，不将不稳定结果采为有效数据。
- warmup.json 导出独立 GPU readiness 状态与最近真实 GPU durations，分别报告首次样本缺失、样本不足、实际耗时不稳。
- 世界切换/断线与客户端退出记录独立原因，不再被称为用户取消；恢复/导出流程保留。

新增回归模拟 37 秒首次执行空档、缺失样本超时、样本收集超时、完整窗口后的持续漂移，以及重初始化重置。

## 性能问题仍未解决

alpha.45 第一次完整 cache ABBA round 中，TAIL transport P50 10.702 / 10.294 ms，PRIMARY 11.587 / 11.617 ms；Primary shade 从 3.172–3.436 ms 增至 4.867–4.934 ms，B1/B2 下降但不足抵消首命中代价。cache train pass 约 0.016–0.017 ms，不能把退化主要归因于训练 dispatch。各 pass 分位数不是逐帧可加量，须继续做 GPU profiler 与图像对照。

ROUGH_DIFFUSE 64 点方向积分、查询及历史访问需要隔离 profile。在真实 GPU / 同画质对照缺失时，不擅自用更粗积分替代以掩盖退化。默认继续 FULL/MONOLITHIC；缓存覆盖已非零，但性能和画质尚未验收。

本版修复测试可靠性，未宣称消除首次驱动执行停顿、网络重置、或缓存性能退化。可复跑 material；测试不应再因首次执行 36 秒空档冒报 variance timeout。真实客户端停顿需要新增诊断与 RTX 复验。
