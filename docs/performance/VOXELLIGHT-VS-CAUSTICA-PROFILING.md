# VoxelLight 与 Caustica：当前性能差距和已验证原因

更新：2026-10-17，alpha.86。精确 RNG 定位 CDF 索引已通过本轮有限范围验收并纳入源码/完整 110-stage 构建，保留 alpha.73 画质修复；完整 alpha.86 包已按用户授权安装，alpha.73 已保留回退备份。多光源 PT 改善 3.89%，目标尚未达到。

历史 Caustica 来自 alpha.50 三轮记录；源码固定为 `14770591086232e13a6b1d5320b0f2f8ef8731e3`。两边光照和阶段职责不完全相同，历史值是性能预算，不能声称当前已完成等工作量对照。原始历史报告见 [alpha.50](alpha50/VOXELLIGHT-VS-CAUSTICA-PROFILING.md)。

本轮冻结输入覆盖普通材质和发光面，没有金属/透明/体积性能代表性。原始分拆、完整RIS单项干预、源码对照、误差与便携工具使用见 [alpha.81–85 工作块报告](ALPHA-81-CANDIDATE-BLOCKS.md)。最新代码、性能/质量有效范围、包身份和保留依据见 [alpha.86](ALPHA-86-RNG-CDF-GUIDE.md)；[alpha.85](ALPHA-85-CDF-GUIDE.md) 继续保留原未达门槛的证据。

新CDF实现上的完整RIS首尾均0.070656ms；缓存发光物几何0.061792、环境几何0.063488、alias选择0.065536、FULL eval0.066624、候选连同emission0.039936ms；各测量窗口中位数2520MHz，输出/RNG逐位一致。差值不相加，也不是严格成本上界。下一项优先完整发光候选选择及精确emission读取，不继续堆叠CDF/点积/开方微调；保留选择再缓存算术反而0.073728ms，更不支持算术是下一确定热点。

剩余不确定性仍包括生产线程分组/类别分歧及编译后资源占用。Nsight硬件计数权限不足，没有寄存器、spill、cache命中或occupancy证明。离线重新分组不能代替生产wave数据。重排必须保持逐路径RNG、PDF支持域和reservoir顺序，并测量新增存储/调度成本；不能通过改用Caustica较轻的光照语义达标。

alpha.86共一个性能客户端、两个画质客户端，全部正常退出0。首次画质场景不齐，只补一次并保留失败记录；补测最初不完整静止配对也排除，6份有效移动/恢复捕获匹配40-section几何，恢复相机/投影一致，无异常重置，噪声/细节代理未见明显退化。独立随机帧指标不冒充clean-reference或同随机帧最大误差认证。110阶段及8项相关检查通过。源码/default bank已保留，完整包没有诊断别名、plan或RR元数据覆盖，native payload与alpha.73一致；安装alpha.73未动，未提交/推送。未重测Caustica、未重复五场景验收。
# 2026-10-17 安装与剩余热点补充

alpha.86 已按用户要求安装，源码与此前累计已验收工作推送至 `origin/main` 的 `1a246db`。后续 alpha.87 上下文复用只在隔离离线回放中实验：准备循环快 5.26%，但完整 RIS 慢 2.63%，因此拒绝且没有启动游戏。完整精确 area emission 的缓存替换影响约 7.34%，单独缓存 RGB 转换或 UV/atlas texel 没有明显收益；不能将冻结替换差值相加或当作帧收益。详细身份、频率检查和未证实原因见 [ALPHA-87-PROPOSAL-CONTEXT.md](ALPHA-87-PROPOSAL-CONTEXT.md)。生产继续 alpha.86，未达到历史 Caustica 性能预算。
