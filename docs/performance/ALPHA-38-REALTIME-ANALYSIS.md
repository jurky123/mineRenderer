## 工作量改善已生效

CACHE 候选合计 4,096,978 次查询、150,554 次命中，命中率约 3.67%；组合为 67,433 / 2,460,224，约 2.74%。SPARSE 复用 595,105 / 5,623,920 条主路径，约 10.58%；组合复用 386,561 / 3,800,640，约 10.17%，完整路径密度约 0.898。较上一版描述性的低命中/低复用明显改善，但不同上传的场景材质比例与运行状态不完全一致，不能当成严格跨版本因果 A/B。

组合各段中位数的均值：primary 1.3723→1.6847ms，resolve 0.0221→0.0546ms；bounce1 2.9841→2.7698ms，bounce2 1.7180→1.6582ms。入口和历史增加约 0.345ms，B1/B2 节省约 0.274ms，省下的追踪仍不足以带来 batch 净收益。scope 中位数不可直接相加当成整帧时间。

## 新计数定位

组合缓存准入失败：未成熟 1,360,087（约查询的 55.28%）、均值误差 635,770（25.84%）、空间/几何 223,504（9.08%）、epoch 173,104（7.04%）、TTL 91。延长 TTL 已消除了大部分过期拒绝，下一步不应继续把寿命无限放宽。

组合 probe 56,457，实际训练 36,586；锁冲突 6,120、空间/hash 占用冲突 13,462，invalid 193，另有少量采样后取消。约三成多的训练提议没有落入缓存；需要去重/优先覆盖未成熟 cells、区分同 cell 的不同平面和哈希冲突，而不是单纯加大总预算。probe_dropped=0 表示上限未被耗尽，不代表训练安排高效。

组合 sparse 中，置信度不足 538,700、均值误差过大 191,751、新暴露/历史失配 610,935；置信度仍是主要调度障碍。材质保护 1,420,246，约主路径的 37.37%，这些表面保留完整追踪有明确材质条件；不能为制造复用率把镜面、发光或透明等保护全部关闭。

## 编辑仍全局失效

组合各段 epoch 4→5、5→7、4→5、5→6；多数最终原因是 scene/edit，只有最后一段是 sun drift bound。CACHE 第二轮一个段发生 4→11 的 scene/edit 失效。日光策略不再是原先唯一的主要失效来源。

源码仍用 `scene.historyGeneration()+RtInvalidationQueue.generation()` 驱动全局 cache/history epoch。后者每次 record 区域都增长，无论修改是否影响当前 cell；这说明区块级依赖/局部失效是下一项结构调整。现有 reason 合并了 terrain 和 edit queue，不能把每次 scene/edit 全部归因于远处修改，下一版应进一步分开。

下一步优先级：按 section/区域局部失效与变更来源统计；训练 cell/平面去重与预算再分配；维持 surface/material 校验下减少历史匹配成本和置信度丢失。当前不需要重复跑相同版本，第三轮仍未通过验收，建议默认保持 FULL。
